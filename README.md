# المستشار النظامي للقبول والتسجيل

تطبيق عربي ثابت يجيب عن حالات القبول والتسجيل بالاعتماد الحصري على ملف **عمليات القبول في المدارس – التعليم الحكومي**، ويعرض مع كل حكم:

- حالة الحكم وخلاصته.
- الشروط أو الخطوات الواردة.
- رقم الصفحة واسم الفقرة أو البند.
- النص الحاكم ورابط فتح الصفحة الأصلية من ملف PDF.

لا يحتاج التطبيق إلى خادم أو قاعدة بيانات أو مفتاح API، ولا يرسل الاستفسارات إلى أي خدمة خارجية.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. افتح إعدادات المستودع، ثم **Pages**.
4. اختر النشر من فرع `main` ومن المجلد `/ (root)`، ثم احفظ.
5. بعد اكتمال النشر افتح الرابط الذي يعرضه GitHub Pages.

## الملفات المهمة

- `index.html`: واجهة التطبيق.
- `app.js`: التفاعل وعرض النتيجة.
- `engine.js`: محرك مطابقة الحالات بالأحكام.
- `data/guide-rules.json`: الأحكام الموثقة والصفحات والفقرات.
- `documents/admission-guide.pdf`: الدليل الأصلي المستخدم مرجعًا.

## تعديل قاعدة الأحكام

يمكن تعديل `data/guide-rules.json` مع المحافظة على الحقول التالية لكل حكم:

`id`, `category`, `title`, `status`, `page`, `paragraph`, `answer`, `steps`, `sourceText`, `keywords`.

يجب مراجعة الصفحة الأصلية قبل إضافة أي حكم جديد، وعدم إدخال معلومات من مصدر آخر إذا كان المطلوب بقاء التطبيق مقيدًا بهذا الدليل.

## تنبيه

الأداة استرشادية وليست قرار قبول نهائيًا. المرجع الملزم هو الدليل الأصلي والجهة المختصة.
